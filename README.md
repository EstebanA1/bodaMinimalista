# Invitación de boda · Juliana & Felipe

Página estática en español, hecha con HTML, CSS y JavaScript. Las imágenes y pistas están dentro de `assets/`.

## Vista local

Inicia `start-preview.cmd` con doble clic y abre [http://localhost:4173](http://localhost:4173). Deja abierta la consola mientras usas la vista previa.

## Vercel

Importa el repositorio en Vercel con el preset **Other**. No necesita comandos de instalación ni compilación; publica la carpeta raíz.
